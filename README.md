# عددروشن | پیش‌نمایش سایت

سایت آزمایشی فارسی عددروشن؛ شامل صفحه اصلی، بلاگ، معرفی و تماس.

برای نمایش در GitHub Pages، از Settings → Pages، گزینه Deploy from a branch را با Branch: main و Folder: / (root) انتخاب کنید.

آدرس پس از انتشار موفق: https://ahmadrastibarzoki.github.io/adadroshan-website/

این نسخه نمونه نمایشی است و فرم تماس هنوز ارسال واقعی ندارد.
